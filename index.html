✅ Project 1: Library Management System

Library Management System is a console-based Python application designed to manage basic library operations efficiently. It allows users to add books, display available books, borrow books, and return books using a simple text-menu interface. The project is built using Python and Object-Oriented Programming (OOP) concepts to keep the code organized and easy to maintain. It is useful for understanding classes, objects, methods, lists, and control flow in Python.

✅ Project 2: Student Management System

Student Management System is a dynamic web application developed using JSP, Servlets, Apache Tomcat, and MySQL in Eclipse to manage student records digitally and efficiently. The system allows users to add, update, delete, and search student information along with academic details like marks and grades. It uses JDBC for database connectivity and follows Object-Oriented Programming principles to ensure structured backend logic. This project reduces manual record handling and demonstrates practical implementation of Java web development concepts and database integration.

GitHub

✅ Project 3: Smart Expense Splitter

Smart Expense Splitter is a responsive single-page web application that simplifies group expense management by allowing users to add friends, record payments, and automatically calculate total expenses, equal shares, and settlement balances. Built using HTML, CSS, and JavaScript, the project features dynamic DOM manipulation, real-time calculation logic, and a modern, mobile-friendly user interface.
